# ADR-0001: Zapis arhitekturnih odluka

- **Status:** prihvaćeno · **Datum:** 2026-11-08

## Kontekst
Proizvod će razvijati više ljudi kroz dulje razdoblje, dijelom samostalno uz Claude. Razlozi odluka moraju ostati zapisani.

## Odluka
Svaka značajna arhitekturna odluka bilježi se kao ADR (kontekst, odluka, posljedice) u `docs/adr/NNNN-naslov.md`. Promijenjena odluka dobiva novi ADR koji zamjenjuje stari.

## Posljedice
Novi član tima ili Claude u novoj sesiji iz ADR-ova razumije zašto je sustav ovakav.
